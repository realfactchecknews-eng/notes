# Clarity

Приложение для учебных конспектов: папки по предметам, редактор, карточки, тесты и ИИ. Работает на GitHub Pages, без бэкенда.

Сайт: https://clarityapp.ru (он же https://realfactchecknews-eng.github.io/notes/)

## Возможности
- **Папки-предметы** и конспекты внутри, поиск по всему тексту
- **Редактор**: заголовки, списки, цитаты, код, выделение маркером, таблицы
- **Рисование**: кисть, ластик, цвет, толщина — рисунок вставляется прямо в конспект
- **Файлы**: вложения до 20 МБ, перетаскивание в конспект, картинки вставляются из буфера (⌘V)
- **ИИ-ассистент** (Groq): структурировать, улучшить, сделать таблицу, краткий конспект, вопросы для самопроверки, термины
- **Карточки**: выделяешь слово в конспекте → ИИ пишет определение по контексту → термин уходит в колоду. Повторение по Лейтнеру (интервалы 1–32 дня)
- **Тесты**: ИИ составляет вопросы с вариантами по конспекту или всему предмету, сразу показывает разбор и оценку
- **Аккаунты**: почта и пароль, свой сервер на Cloudflare. Гость может завести аккаунт из личного кабинета — записи переедут вместе с ним
- **Личный кабинет**: символы напечатанные и стёртые, время в приложении, созданные конспекты, карточки, средний результат тестов и активность по дням
- **Пользовательское соглашение** — `terms.html`

## Экспорт
Кнопка «⤓» в панели редактора: PDF (через печать браузера — «Сохранить как PDF»; в окне печати надо снять галочку «Колонтитулы», иначе браузер добавит по углам свой адрес и номера страниц) или Word (.doc). Можно выгрузить один конспект или весь предмет. В документе обложка, автособираемое содержание по заголовкам, водяной знак и вёрстка под печать.

## Горячие клавиши
`⌘K` — поиск · `⌘S` — сохранить · `Esc` — закрыть окна · `⌘Z` в рисовалке — отменить штрих

## Данные
**С аккаунтом** — свой сервер на Cloudflare Workers + база D1 (`api/worker.js`):
папки, карточки и результаты тестов одной записью, каждый конспект отдельной строкой.
Синхронизируется между устройствами.

**Без аккаунта** — IndexedDB этого браузера. При первом входе предлагается перенести записи в аккаунт.
Локальная копия пишется всегда, поэтому при недоступном сервере приложение открывается офлайн,
а несохранённое уходит, когда связь возвращается.

Пароли хранятся PBKDF2-хешем с солью (100 000 итераций — потолок Workers), сессия — подписанный HMAC-токен на 30 дней.

### Сервер
```bash
cd api && npx wrangler deploy          # выкатить
npx wrangler d1 execute clarity-db --remote --file=schema.sql   # схема
```
Адрес: https://clarity-api.realfactchecknews.workers.dev · база `clarity-db` · секрет `SECRET` в wrangler secret.

Картинки крупнее 400 КБ ужимаются до 1600 px и JPEG 0.82 прямо в браузере, чтобы конспекты не раздувались.

## ИИ
Работает сразу: общий ключ Groq вшит в `app.js`. Код открыт, значит ключ виден всем — если его исчерпают или заблокируют, надо выпустить новый на console.groq.com/keys и заменить.
В «⚙ Настройки ИИ» можно подставить свой ключ и выбрать модель — сохранится только в твоём браузере.
